## 1. Midjourney 的"品味学习"机制

| 功能 | 机制 | 输出 / 用法 |
|---|---|---|
| **Personalization（--p）** | 早期版本让用户对图片做**成对评分**，再加上 Explore 页的"喜欢"，**至少 200 次**才能解锁（[The Decoder](https://the-decoder.com/midjourneys-new-personalized-image-feature-lets-you-generate-images-in-your-preferred-style/)）。有二手报道称门槛后来降到 **40 次即可建立初始画像，约 200 次趋于稳定**（[getcoai](https://getcoai.com/?p=41159)），官方现行文档没有重复这两个数字。现行官方文档写的是：成对评分已改为**从网格中挑选喜欢的图片**，页面顶部有进度条，选够数量后解锁 Global Profile；解锁之后才能再建多个 Profile（[Personalization 文档](https://docs.midjourney.com/hc/en-us/articles/32433330574221-Personalization)）。 | 在提示词后加 `--p` 使用默认画像，或 `--p <ID/code>` 指定某个画像。**画像更新后 code 会随之变化**，相当于版本标签，可以分享给别人复用（同上）。`--s` 控制强度，0 为关闭，100 为标准，1000 为最强（[The Decoder](https://the-decoder.com/midjourneys-new-personalized-image-feature-lets-you-generate-images-in-your-preferred-style/)）。 |
| **Moodboards** | 2024-12-16 随新的个性化基础设施一起上线，支持多个画像，用户**上传或选取一组图片**来构建风格。官方说明图片越多样，模型的混合方式越复杂（[Profiles and Moodboards](https://updates.midjourney.com/profiles-and-moodboards/)）。 | 每个 moodboard 有一个 ID，同样通过 `--p`/`--profile` 调用。适用于 V6/V7，与 `--sv`、`--sw` 不兼容。官方的定位是：表达的审美范围比 `--sref` 更宽（[Moodboards 文档](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards)）。 |
| **Style Tuner（/tune，已归为旧功能）** | 用户选择 16/32/64/128 个"风格方向"，系统按方向生成**成对**图片，用户在每一对里选一张，两张都不喜欢可以都不选（[官方 Style Tuner](https://docs.midjourney.com/style-tuner)，[Midlibrary](https://midlibrary.io/midguide/midjourney-style-tuner-explained)）。 | 生成 `--style <code>`，多个 code 可以用连字符组合。只支持 V5.2（[Legacy Features](https://docs.midjourney.com/docs/style-tuner)）。 |
| **Style Creator（新）** | 用户每轮**点选**符合目标风格的样图，系统会同时学习**选中的和没选的**图片。官方说明多数风格 5–10 轮稳定，10–15 轮补充细节，15 轮以后变化很小（[Style Creator](https://docs.midjourney.com/hc/en-us/articles/41308374558221-Style-Creator)）。 | 产出可复用的 `--sref` code。 |
| **--sref** | 可以直接用参考图，也可以用数字 code。`--sref random` 会随机分配一个 code，Explore 页可以浏览这些 code。`--sw` 取值 0–1000，默认 100（[Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)）。 | |

**可借鉴到视频的部分**：
1. "画像"本质上是一个**可版本化、可分享的短 code**，背后是一个从用户选择中学出来的偏好向量。
2. 用户反馈的形式经历了三步演进：成对比较，到网格多选，再到"选中即正例、没选即弱负例"的多轮交互（Style Creator）。网格多选的成本比成对比较低。
3. 系统区分两种画像：从少量正例图片直接聚合出来的（Moodboard），和从大量偏好交互里学出来的（Personalization）。
4. 强度参数（`--s`/`--sw`）在"风格向量"和"内容需求"之间做插值。

对我们来说，可以对应成：用户上传的示例模板相当于 Moodboard，用户在候选模板之间的点击和成对选择相当于 Personalization，最后为每个类别生成一个"类别画像 code"。

## 3. 学术文献

### (a) 剪辑风格与模板理解
- **AutoTransition**（ECCV 2022，ByteDance）：[arXiv 2207.13479](https://arxiv.org/abs/2207.13479)。用**剪辑软件的公开模板**构建数据集，先学习转场 embedding，再用多模态 Transformer 融合画面和音频来推荐转场。对我们的意义：证明"模板数据集加转场 embedding"的做法可行。
- **V-Trans4Style**（NeurIPS 2025）：[arXiv 2501.07983](https://arxiv.org/abs/2501.07983)。在推理阶段通过风格条件模块调整转场推荐，使其贴近目标制作风格，并构建了 AutoTransition++ 数据集（5 种风格，共 6000 个视频）。对我们的意义：转场序列本身可以作为风格特征。
- **Edit3K**：[arXiv 2403.16048](https://arxiv.org/abs/2403.16048)。数据集覆盖 3094 种剪辑组件（特效、动画、转场、滤镜、贴纸、文字）和 61.88 万个视频，学到的表示能把**组件外观和底层素材内容分开**。对我们的意义：最贴近"模板风格 embedding"的工作，可以帮助识别模板里用了哪些特效和滤镜。
- **MovieCuts**（ECCV 2022）：[arXiv 2109.05569](https://arxiv.org/abs/2109.05569)。约 17.4 万个片段，标注了 10 类剪切类型。**MovieShots**（ECCV 2020）：[arXiv 2008.03548](https://arxiv.org/abs/2008.03548)。标注了 5 类景别和 4 类运镜。对我们的意义：剪切类型、景别、运镜都可以统计成风格直方图。
- **VEU-Bench**（CVPR 2025）：[arXiv 2504.17828](https://arxiv.org/abs/2504.17828)。包含 19 个剪辑理解任务，测试发现部分视频大模型的表现不如随机猜测。对我们的意义：不能直接依赖通用视频大模型来理解剪辑手法。
- **Automatic Non-Linear Video Editing Transfer**（Google，CVPR'21 AICC workshop）：[arXiv 2105.06988](https://arxiv.org/abs/2105.06988)。从一个视频中提取每段的取景、内容类型、播放速度和光照，再迁移到新素材上。对我们的意义：给出了一组可解释的风格特征。
- **Match Cutting**（WACV 2023，Netflix）：[论文](https://openaccess.thecvf.com/content/WACV2023/papers/Chen_Match_Cutting_Finding_Cuts_With_Smooth_Visual_Transitions_WACV_2023_paper.pdf)。研究在视觉上平滑衔接的剪切点。
- **卡点与音乐对齐**：MVAA [arXiv 2506.18881](https://arxiv.org/abs/2506.18881) 先把关键帧放到节拍位置，再用扩散模型补中间帧。MV-Crafter [arXiv 2504.17267](https://arxiv.org/abs/2504.17267) 用动态节拍匹配实现"cut-to-the-beat"。工具层面，**TransNet V2** 可做镜头切分（[arXiv 2008.04838](https://arxiv.org/abs/2008.04838)），**Beat This!**（ISMIR 2024）可做节拍和强拍检测（[arXiv 2407.21658](https://arxiv.org/abs/2407.21658)）。对我们的意义：剪切点和节拍的对齐率是一项硬特征，适合日系舞蹈类卡点模板。

### (b) 可用于风格相似度的表征模型
- **CLIP** [arXiv 2103.00020](https://arxiv.org/abs/2103.00020)、**SigLIP** [arXiv 2303.15343](https://arxiv.org/abs/2303.15343)：逐帧语义 embedding，同时支持用文本描述风格。
- **CSD**（风格描述子）[arXiv 2404.01292](https://arxiv.org/abs/2404.01292)：专门针对**风格**而不是内容的图像相似度，可用于色调和画风判断，弥补 CLIP 偏重语义的问题。
- **DreamSim**（NeurIPS 2023）[arXiv 2306.09344](https://arxiv.org/abs/2306.09344)：拼接 CLIP、OpenCLIP 和 DINO 的 embedding，再按人类相似度判断微调，对布局和颜色更敏感。
- **X-CLIP**（ACM MM 2022）[arXiv 2207.07285](https://arxiv.org/abs/2207.07285)：同时在帧和词两个粒度上做视频-文本对比学习。
- **VideoMAE**（NeurIPS 2022）[arXiv 2203.12602](https://arxiv.org/abs/2203.12602)：自监督视频表征，能捕捉运动信息，在约 3–4k 个视频的小数据上也能训练。
- **InternVideo2**（ECCV 2024）[arXiv 2403.15377](https://arxiv.org/abs/2403.15377)：视频编码器规模达 6B 参数，融合视频、音频和语音信息。
- **LanguageBind**（ICLR 2024）[arXiv 2310.01852](https://arxiv.org/abs/2310.01852)：以语言为中心对齐视频、音频等多种模态，可用于对模板的配乐做 embedding。

### (c) 视频美学与质量评估
- **DOVER**（ICCV 2023）[arXiv 2211.04894](https://arxiv.org/abs/2211.04894)：把视频质量拆成"美学"和"技术"两个维度分别打分。
- **FAST-VQA**（ECCV 2022）[arXiv 2207.02595](https://arxiv.org/abs/2207.02595)：通过 fragment 采样大幅降低计算量，1080P 视频的 FLOPs 减少 99.5%。
- 对我们的意义：可以作为质量先验，过滤低质模板。但它们评的是通用质量，不能代表某一类风格的好坏。

### (d) 成对偏好与少样本品味学习
- **Bradley–Terry 模型**（Biometrika 1952）：P(i 优于 j) = τi/(τi+τj)，是所有成对偏好模型的基础（[说明](https://genstat.kb.vsni.co.uk/knowledge-base/rbradley/)，[百科](https://encyclopediaofmath.org/wiki/Bradley–Terry_model)）。
- **Pick-a-Pic / PickScore**（NeurIPS 2023）[arXiv 2305.01569](https://arxiv.org/abs/2305.01569)：用真实用户的二选一数据训练基于 CLIP 的偏好打分器。**HPS v2** [arXiv 2306.09341](https://arxiv.org/abs/2306.09341)，**ImageReward**（NeurIPS 2023）[arXiv 2304.05977](https://arxiv.org/abs/2304.05977)：同类工作，都是从大规模成对比较中学出通用偏好。**VideoReward** [arXiv 2501.13918](https://arxiv.org/abs/2501.13918)：把这一思路扩展到视频，按画质、运动和文本对齐分维度打分。
- **ViPer**（ECCV 2024）[arXiv 2407.17365](https://arxiv.org/abs/2407.17365)：用户对少量图片写下评价，LLM 把评价提炼成"喜欢 / 不喜欢的视觉属性"列表。对我们的意义：画像可以做成**可解释的属性列表**。
- **PPD**（CVPR 2025）[arXiv 2501.06655](https://arxiv.org/abs/2501.06655)：VLM 把**约 4 组成对偏好**编码成用户 embedding。对我们的意义：说明少样本的成对偏好就足以形成可用的画像。
- **个性化美学 PIAA**（ICCV 2017）[论文](https://openaccess.thecvf.com/content_iccv_2017/html/Ren_Personalized_Image_Aesthetics_ICCV_2017_paper.html)：在通用美学分数上学一个**残差偏移**来适配个人，并配合主动学习选样。
- **主动偏好学习**：Bıyık & Sadigh（CoRL 2018）[arXiv 1810.04303](https://arxiv.org/abs/1810.04303) 提出批量主动选择最有信息量的对比对，2024 年的扩展用 DPP 保证同一批对比对的多样性（[arXiv 2402.15757](https://arxiv.org/abs/2402.15757)）。
- **Rocchio 相关反馈**：新查询 = α·原查询 + β·正例中心 − γ·负例中心（[Stanford IR Book](https://nlp.stanford.edu/IR-book/html/htmledition/the-rocchio71-algorithm-1.html)）。可以作为冷启动阶段最简单的基线。

## 4. 启示与推荐方案

**（一）模板特征：拆成三类，分别向量化**
1. **视觉风格**：每个镜头取 1–3 帧，计算 SigLIP/CLIP 语义向量和 CSD 风格向量，再统计色彩直方图、亮度和饱和度。
2. **剪辑语法**（用 TransNet V2 切镜头，用 Beat This! 测节拍）：
   - 镜头数、平均镜头时长及其方差
   - **剪切点落在节拍上的比例**
   - 转场类型分布（可参考 AutoTransition、Edit3K 的类别体系）
   - 景别和运镜分布（MovieShots 的类别）
   - 变速和特效密度
   - 文字和字幕的占屏比例与样式
3. **音频与语义**：配乐的 BPM 和 LanguageBind/CLAP 类音频 embedding，加上用 VLM 生成的简短"风格标签"（参考 ViPer 的属性列表）。
4. **质量先验**：用 DOVER 的美学和技术分数做门槛，不参与风格相似度计算。

**（二）类别画像的学习流程**
1. **冷启动（相当于 Moodboard）**：对用户的 N 个正例，逐个特征块做 L2 归一化后取均值，作为 Rocchio 的初始质心。参考 PinnerSage，N 较大时用层次聚类保留 **2–4 个 medoid**，避免把多种子风格平均成"四不像"。
2. **交互阶段（相当于 Personalization / Style Creator）**：每轮展示一个 4–8 格的候选网格，**选中视为正例，跳过视为弱负例**（Style Creator 的做法）。另外插入少量成对对比，对比对按不确定性加 DPP 多样性主动挑选（Bıyık & Sadigh）。在冻结的特征上训练一个线性 Bradley–Terry 模型 s(x)=wᵀφ(x)，以 Rocchio 质心作为先验正则。参照 PPD 和 Style Creator 的经验，约 5–10 轮即可大致稳定。
3. **产出**：把 w、medoid 和属性标签打包成**带版本号的类别画像 code**（参照 `--p` code 随画像更新而变化的设计），提供一个强度参数，在"类别画像"和"当前查询"之间插值（参照 `--s`/`--sw`）。
4. **检索创作者**：先给每个模板打分，再按创作者聚合（如 top-k 均值或命中率），结合 DOVER 质量分和活跃度排序。最后在结果页提供 Like / Dislike / Generate Similar 按钮（参照 TikTok One），把反馈回流到第 2 步。
