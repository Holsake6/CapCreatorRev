# 舞蹈模板审美标准 v1

## 当前结论

这 26 条可以作为第一批正面参考，但还不能直接当成精确评分模型。数据只有正面案例，而且不少逐条分析字段出现完全相同的描述，因此这类重复文本仅作为弱证据。

## 核心偏好

1. 人物是第一视觉层级，主体清楚，动作可读。
2. 包装有统一主题，并且不遮挡或压过人物。
3. 剪辑、文字、贴纸和特效应跟随动作节点或音乐重拍。
4. 前 3 秒快速建立人物、舞蹈或视觉主题。
5. 替换素材后仍然成立，优先低到中等替换门槛。
6. 用多条作品判断创作者，不能用一条爆款下结论。

## 单条视频评分

| 维度 | 权重 |
| --- | ---: |
| 节奏与同步 | 25 |
| 包装设计与主题统一 | 25 |
| 人物与动作可读性 | 20 |
| 模板可替换性 | 15 |
| 创意与完成度 | 15 |

评分必须附具体画面证据和时间戳。总分只用于排序，最终判断仍看各维度证据。

## 可接受的不同风格

- 手写涂鸦或歌词包装
- 可爱贴纸或少女感
- 极简人物或舞蹈驱动
- 拼贴、抠像或版式设计
- 群舞或偶像舞蹈
- 场景与镜头语言驱动

这些是并列方向，不要求每条作品都带贴纸、手写字或可爱元素。

## 创作者判断

每位候选创作者至少抽查 5 条近期舞蹈模板，检查优质作品占比、风格稳定性、包装与节奏能力、原创设计能力和近期持续产出。

## 仍需校准

- 音乐类型偏好
- 快切与完整长镜头的偏好
- 对复杂变速、定格和循环的容忍度
- 对暗色与夜景风格的偏好强度
- 明确的反面案例及淘汰边界
