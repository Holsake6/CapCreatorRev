# CapCut 创作者审核工具：当前进度

更新日期：2026-10-07

## 本次重构

- 原单文件程序（`capcut_local.py`，后端逻辑与 HTML 混在一起）拆分为明确的前后端：
  - `backend/`：Python 标准库 JSON API，数据从十余个 JSON 文件改为单个 SQLite 数据库。
  - `frontend/`：纯静态 HTML/CSS/JS 页面，通过 API 读写数据。
- 新增根目录启动 / 停止脚本：`run.sh`、`stop.sh`（Windows，Git Bash）与 `run.command`、`stop.command`（macOS）。
- 首次启动自动导入旧版 JSON 数据（快照保存在 `backend/data/legacy/`）。
- 已归类作者排除名单由文本文件改为审核页内编辑。
- 视频分析在非 macOS 系统自动跳过，扫描仍可在 Windows 运行。

## 当前可用功能

- 舞蹈模板创作者发现、人工审核、已通过作者筛选、CSV 导出和手动刷新。
- 舞蹈审美学习：26 条正面案例、人工审核反馈、手动调权和本地视频分析（macOS）。
- 独立“新类别工作区”：只接收正面案例，不继承舞蹈审美或反向提示词。

## 现行规则

- 舞蹈主界面继续筛选日本区、非 AI、舞蹈模板创作者。
- 主页投稿总数和 uses 大于等于 3000 的作品数只用于排序，不再是审核通过硬门槛。
- 7 天 / 1000 uses 规则是当前及未来类别（含未来 AI 类别）统一使用的数据硬门槛。
