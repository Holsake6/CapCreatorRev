# 模板素材上传指南（可直接转发给客户）

我们会用这批模板来“学习”每一类视频的风格，再去 CapCut 寻找能做出同类模板的创作者。
请按下面的方式上传，**整理得越清楚，系统学得越准**。

## 一、推荐方式：Dropbox「文件请求」（客户不需要注册账号）

1. 我方在 Dropbox 创建一个“文件请求”（<https://www.dropbox.com/requests> → 新建请求），把生成的链接发给客户。
2. 客户打开链接，直接把文件夹或 zip 拖进去上传即可，**不需要 Dropbox 账号**。
3. 文件会出现在我方 Dropbox 的对应文件夹里。我方把这个文件夹的分享链接（或者本机同步后的文件夹路径）粘贴到系统的“示例与设置 → 从链接/网盘/文件夹导入”，勾选“按子文件夹名自动分到不同类别”，即可一次导入全部类别。

> 为什么推荐它：一个链接即可上传，文件夹结构会完整保留；系统能直接下载 Dropbox 文件夹（自动打包成 zip），不需要人工逐个下载。

## 二、其他可选方式

| 方式 | 客户操作 | 我方导入方法 | 备注 |
|---|---|---|---|
| **Google Drive 文件夹** | 上传到一个文件夹，共享设为“知道链接的任何人都可查看” | 直接粘贴文件夹链接 | 单个文件夹超过 50 个文件时，请客户先打包成一个 zip 再上传 |
| **任意网盘的 zip 直链** | 把整个素材打包成 **一个 zip** | 粘贴 zip 下载链接 | 需要是“点开即下载”的直链 |
| **飞书云空间 / 百度网盘 / 阿里云盘**（中国大陆常用） | 上传到共享文件夹 | 我方手动“下载整个文件夹”为 zip，再拖进系统或粘贴本机路径 | 这些网盘需要登录或客户端，无法由程序自动下载 |
| **只有 CapCut 模板链接** | 把链接整理成一个 `links.txt`（每行一个），或表格导出为 CSV | 直接把文件或文字粘贴进系统 | 系统会自动读取标题、作者和预览视频 |

## 三、文件夹怎么整理（重要）

```
客户素材/
├── 舞蹈/                 ← 一个文件夹 = 一个类别（文件夹名就是类别名）
│   ├── 01.mp4
│   ├── 02.mp4
│   └── 反例/             ← 可选：明确“不要这种”的视频，放在名为“反例”的子文件夹
│       └── x.mp4
├── 卡点变装/
│   ├── a.mp4
│   └── links.txt         ← 也可以放 CapCut 模板链接，每行一个
└── 旅行vlog/
    └── ...
```

- **每类至少 5 个，建议 15–30 个**正例视频；风格差异较大时可以多给一些。
- 最好提供**模板成片的原始导出视频**（mp4/mov），不要录屏、不要二次压缩、不要加水印。
- 视频时长 5–60 秒即可，系统只分析前 60 秒。
- 一个类别里如果其实有两三种不同风格，也没关系，系统会自动找出几种“代表风格”；但不要把完全不同的类别混在一个文件夹里。
- 反例可选，但很有用：例如“同样是舞蹈，但这种包装太土 / 太乱”。
- 文件名可以写简短说明（如 `手写涂鸦_双人.mp4`），系统会把文件名当作标题参考。

## 四、我们会对素材做什么

- 只在我方电脑本地分析（提取剪辑节奏、卡点程度、色调、包装和人物构图等特征），**不会上传到任何第三方 AI 服务**。
- 素材只用于本项目的风格学习与创作者筛选。
