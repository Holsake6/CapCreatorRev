# “学习一个视频模板”是怎么定义和实现的

> 背景调研（Midjourney 个性化、同类产品、论文）见 [research/视频模板自学习_调研.md](research/视频模板自学习_调研.md)。

## 1. 定义：模板 = 一组可测量的剪辑决策

CapCut 模板的“风格”主要不在拍了什么，而在**怎么剪**：切镜节奏、卡点是否落在重拍、色调、包装元素、版式和人物构图。
因此系统给每个视频提取一份可解释的 **模板基因（Template DNA）**，全部在本机用 OpenCV + ffmpeg 计算（`capcreator/dna.py`）：

| 组 | 特征 | 怎么测 |
|---|---|---|
| 节奏 | 切镜频率、镜头时长变化、画面冲击点密度、**切点卡拍**、**画面律动跟拍** | 颜色直方图跳变 + 像素差判定切镜；15fps 画面变化峰值 = 冲击点；切点卡拍 = 冲击点落在音乐重音（频谱通量峰值）±90ms 内的比例减去随机概率；画面律动跟拍 = 画面变化曲线与音乐重音曲线的相关性，相对随机错位的 z 分数（舞蹈模板大多一镜到底，靠这一项而不是切镜体现卡点） |
| 运动 | 运动强度、运动起伏 | 相邻帧灰度差的均值/方差 |
| 包装 | 闪白/闪光、画面元素密度、固定图形占比 | 亮度突增；Canny 边缘密度；跨帧持续存在的边缘（文字、边框、贴纸） |
| 版式 | 边框留白、分屏/拼贴 | 边缘静止且均匀的行列；跨帧贯穿画面的直线接缝 |
| 色彩 | 亮度、对比度、饱和度、色彩丰富度、暖色倾向、14 格色调分布 | HSV/RGB 统计（Hasler–Süsstrunk colorfulness） |
| 主体 | 人脸出现率、人脸大小（近景程度）、人物出现率、动作是否居中 | Haar 人脸 + HOG 人体检测；运动能量重心 |
| 音乐 | BPM、重音密度、响度 | 频谱通量自相关 |
| 可选：画面内容 | CLIP 向量 | 安装 `requirements-clip.txt` 后自动启用 |

合成视频测试（`tests/test_dna_and_taste.py`）验证：同样的快切，切在节拍上时卡点同步度 ≈ 1.0，整体偏移半拍时 ≈ 0。

## 2. 学习：像 Midjourney 一样，从示例和点选里学“品味”

每个类别一个独立模型（`capcreator/taste.py`），训练数据有四种来源，权重不同：

| 来源 | 含义 | 权重 |
|---|---|---|
| 示例视频 / 模板链接（客户提供） | Moodboard：这就是我们要的 | 1.0 |
| 风格训练页的点选 | 选中 = 喜欢；没选 = 弱不喜欢；“完全不像” = 明确反例；每个选中都“赢过”同组每个没选中的（成对比较） | 0.8 / 0.25 / 0.8 / 成对 0.5 |
| 审核结论 | 通过作者的类别作品 = 正例；排除作者的作品 = 反例（原因涉及画面/包装/节奏时权重更高） | 0.6 / 0.5 或 0.12 |
| 扫描到但没人标注的模板 | 背景分布（PU learning）：让“CapCut 上本来就很常见”的特征不被误当成风格 | 0.08 |

模型本身是带先验的正则化逻辑回归 + Bradley–Terry 成对项，特征先按全体候选做稳健标准化：

1. **冷启动**：只有示例时，先验方向 = “示例里一致、而在全体里少见”的特征；再用 k-medoids 从示例里挑出最多 4 个**代表案例**（参考 Pinterest PinnerSage），“接近任一代表案例”本身也是一个特征，所以一个类别可以同时容纳几种子风格。
2. **越点越准**：标注越多，正则越弱，数据接管先验；置信度 = 1 − e^(−有效标注数/30)，约 30 轮点选后稳定（Midjourney 个性化约 40 次起步）。
3. **主动选样**：每组网格 = 1/3 最像的 + 1/3 模型最拿不准的 + 其余离已标注样本最远的；同一作者每组只出一个。
4. **档案编号**：每次重训生成 `类别-v版本-指纹`（如 `danc-v12-3f9a2c`），类似 `--p` 代码，可以对照“哪一版模型找出了哪些作者”。
5. **可解释**：模型权重直接对应特征，页面显示“偏好：画面变化更贴合音乐重拍、颜色更鲜艳…；避开：分屏拼贴…”，每条作品也会显示主要加减分原因。

## 3. 检索：从模型到创作者

1. 入口：类别示例模板（CapCut 的“相关推荐”就是最好的相似检索）→ 类别关键词的 explore 页 → **从 CapCut 站点地图（约 5 万个日文专题页）自动匹配的专题页**（随手输入的关键词大多没有专题页，例如“旅行”是 404，但站点地图里有“旅行vlogテンプレート”）→ 以往见过的同类模板。
2. 沿相关推荐广度优先扩展（默认 1200 页），先用便宜的规则过滤（非 AI、日文、7 天 / 1000 uses、类别信号）。
3. 文字分排序后，只下载前 80 位作者的代表作品预览视频做 DNA 分析（分析后即删除视频，只保留特征）。
4. 作者风格分 = 0.65 × 前三条作品平均匹配度 + 0.35 × 匹配作品占比，作品少时向 50 收缩。
5. 综合分 = 审美 70%（文字代理与视频风格按“风格强度”混合，类似 `--s`）+ 数据质量 30% + 审核备注关键词修正（±30）。
6. 审核时粘贴作者主页链接，会通过 CapCut 应用接口拉取**该作者全部模板**并核查类别占比，而不是只看扫描碰到的几条。

## 4. 实测验证（2026-10-27，真实 CapCut 数据）

- **抓取**：模板详情页、专题页、ORICON 热歌榜、作者主页接口全部可用；一次完整舞蹈扫描 2 分 22 秒（1078 条模板、分析 19 条视频、新增 11 位，无重复）。
- **视频分析速度**：改用 ffmpeg 直接解码成 15fps 小图后，一条 60 秒 720p 视频从约 21 秒降到约 7 秒。
- **用已有 100 条审核结论做留一法验证**（每次拿掉一位作者，用其余结论训练，再给他打分）：只看视频特征，区分“通过”和“排除”作者的 AUC = 0.80（只有 6 位通过作者）。学到的偏好与人工审美标准一致：人脸/人物出现更多、偏暖色、对比更强、音乐更快。
  - 对舞蹈类别，手写的文字审美规则本身已经很强（AUC 0.91），叠加视频分暂时没有进一步提升，所以舞蹈的视频风格强度设为 20。视频模型主要服务于**没有人工规则的新类别**。
- **内容型类别（用 6 个宠物 mp4 + 2 个舞蹈反例测试）**：只用剪辑特征时，宠物模板和舞蹈模板分不开；开启 CLIP 后，三条狗狗模板排到前三，纯舞蹈和新闻类模板排到最后。结论：**按“剪法”定义的类别（卡点、手写包装、舞蹈剪辑）模板基因就够；按“内容”定义的类别（宠物、旅行、美食）建议开启 CLIP**（`./安装依赖.command --clip`，约 1–2GB）。

## 5. 已知局限与下一步

- CapCut 网页给作者的 secUid 会随地区/服务器变化（同一作者在 Mac 和云端拿到的不同），所以“已见作者”同时按名字匹配；同名的不同作者会被当成已见（宁可漏，不重复）。
- 扫描时每位作者通常只碰到 1–2 条作品；作者的完整作品列表只能通过主页分享链接读取（审核页“从主页链接读取”会自动核查最近约 500 条）。CapCut 网页没有公开的作者作品页，站内搜索需要反爬签名，没有接入。
- 主页核查里的“类别占比”只按标题/描述关键词计算；很多舞蹈模板标题只写歌名，所以这个比例偏低，仅供参考。

- 人脸/人体检测用的是 OpenCV 自带的传统检测器，对重度特效画面不够准；所以舞蹈的“人物+运动”视频门槛只在没有文字证据时才淘汰作者。
- 转场类型、字幕样式、特效种类（Edit3K / AutoTransition 那类细粒度识别）还没有做，需要专门模型。
- CLIP 语义通道默认关闭（依赖约 1–2GB），装上后自动参与训练；已有的视频分析结果会自动补算 CLIP 向量。
- 视觉门槛已用 56 条真实模板校准；拿到客户真实素材后，仍应看“风格档案”页的偏好是否符合直觉。
